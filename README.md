## Описание

Это простое графическое приложение (GUI), созданное на Python, которое позволяет искать пользователей на платформе GitHub с помощью официального **GitHub API**.

**Основные возможности:**
*   Поиск пользователей по имени или никнейму.
*   Отображение списка найденных пользователей с их логинами и ссылками на профили.
*   Добавление пользователей в избранное.
*   Сохранение списка избранных пользователей локально в файл `data/favorites.json`.

Проект создан в учебных целях для демонстрации работы с API, создания интерфейсов на Tkinter и использования систем контроля версий.

---

## Как использовать API (GitHub Search Users)

Приложение использует публичный REST API GitHub. Для поиска пользователей используется эндпоинт:

`GET https://api.github.com/search/users`

**Параметры запроса:**
*   `q` (обязательный): Строка поискового запроса (например, имя пользователя, email или просто текст).

**Пример запроса из кода:**
Приложение отправляет GET-запрос с заголовком `Accept: application/vnd.github.v3+json` для получения данных в формате API версии 3.

Ответ от сервера содержит список пользователей в поле `items`. Из каждого объекта извлекаются следующие данные:
*   `login` (никнейм)
*   `html_url` (ссылка на профиль)
*   `avatar_url` (ссылка на аватар)
*   `id` (уникальный ID)

## Примеры использования

### 1. Поиск пользователя

1.  Запустите приложение (`app.py`).
2.  Введите никнейм интересующего вас пользователя в поле поиска (например, `torvalds` или `gvanrossum`).
3.  Нажмите кнопку **«Найти»**.
4.  В списке ниже появятся результаты. Вы можете нажать на пользователя, чтобы увидеть его данные в консоли.

### 2. Добавление в избранное

1.  Найдите пользователя с помощью поиска.
2.  В списке результатов найдите нужного человека.
3.  Нажмите кнопку **«В избранное»** рядом с его именем.
4.  Пользователь будет добавлен в локальный список избранного, который сохраняется в файл `data/favorites.json`.

### 3. Просмотр избранного

В текущей версии приложения просмотр избранного доступен через вывод в консоль. При запуске программы список избранных пользователей загружается автоматически.
